# MyLife App

A modular, customizable personal app for tracking and organizing day-to-day life: medications,
blood pressure, weight, groceries, journal, TV/movies and more. Planned for use by Kevin and his
father, each with their own modules.

Status: planning. See `CLAUDE.md` for the project principles and current status, and
`docs/modules.md` for the module ideas.

This repository contains code only. No personal or medical data belongs here.
